# DockStudio 富集评测报告（DUD-E hivpr，2026-11-20）

**结论：在本次采样规模下，vina 打分对 DUD-E hivpr 没有显示出富集能力。**

这个结果对项目不利，但它是真实测出来的，照实报告。

## 数据与参数

| 项 | 值 |
|---|---|
| 数据集 | DUD-E `hivpr`（HIV 蛋白酶，真实活性/诱饵） |
| 采样 | 40 活性 + 120 诱饵（1:4.0，**非 DUD-E 原比例**） |
| 受体 | DUD-E `receptor.pdb` |
| 盒中心 | `crystal_ligand.mol2` 重原子质心 (20.21, -2.78, 17.92) |
| 引擎 | vina 1.2.7，exh=4，num_modes=3，seed=42 |
| 全部对接成功 | 160/160（无失败） |

## 指标

| 指标 | 值 | 随机基线 | 判读 |
|---|---|---|---|
| AUROC | **0.4808** | 0.5 | 低于随机 |
| BEDROC(α=20) | **0.3576** | ~0.02 | 略高于随机 |
| EF1% | **2.00** | 1.0 | 2 个分子里 1 个活性，样本量极小 |
| EF5% | **1.00** | 1.0 | 与随机无异 |

## 为什么是这个结果（诚实分析）

1. **样本量太小**：EF1% 在 160 个分子上只有 2 个位置，单个分子就能让它翻倍或归零。
   这个数字不能作为结论，只能作为流程可跑通的证据。
2. **vina 打分与 DUD-E 诱饵的已知偏差**：DUD-E 诱饵是按物理性质匹配但拓扑不同的分子，
   这类分子常被 vina 打分过高（文献中 DUD-E 上的 AUROC 普遍在 0.5–0.7）。
   0.48 落在该区间的低端。
3. **单打分函数、单种子、无共识**：本评测用的是裸 vina 亲和力，没有叠加 SILE/CNN/IFP 共识。
   项目里的 `compute_exponential_consensus_ranking` 正是为此设计，但本次未启用。

## 这次评测**证明**了什么

- 富集评测链路端到端可跑：真实 DUD-E 数据 → 受体准备 → 160 次真实对接 → 指标计算，无失败。
- `compute_enrichment_metrics` 在真实数据上可用（此前只有合成数据单元测试）。
- 盒中心由晶体配体质心自动确定，未凭空编造。

## 这次评测**不能**证明什么

- 不能据此判定 DockStudio 的筛选能力优劣：样本量、单打分函数、非原比例采样都不足。
- 要达到可发表/可对外引用，至少需要：完整 DUD-E 比例（1:40）、≥20 个靶点、
  并用项目自身的共识打分（ECR）而非裸 vina。

## 建议的下一步

1. 换用 `compute_exponential_consensus_ranking` 重跑，比较裸 vina vs 共识的 AUROC 差值。
2. 扩到完整 1:40 比例（hivpr 有 1395 活性 / 36278 诱饵，单卡约 5–6 天）。
3. 若目标是对外声明，优先 LIT-PCBA（本次因镜像不可达未做），它是更被认可的基准。
